# Учебный продукт 0.7.0

Локальная рабочая версия от 11.10.2026. Описывает реализованный код; публикация и проверка интерфейса пользователем ещё не подтверждены.

## Как учится пользователь

1. На главной открывает «Мой маршрут». Начальное направление L1 включает пять занятий: адресация, DNS, маршруты, транспорт и TLS.
2. Читает короткий материал, видит первичные источники и границы учебной модели. Отмечает прочтение и отвечает на вопрос. Первый ответ фиксируется для текущего посещения занятия; объяснение доступно после ответа.
3. Проходит лабораторию с подсказками, затем самостоятельно. Исходный отказ, команды, изменения и свежие проверки связаны состоянием виртуального стенда.
4. Разбирает недостающие действия, составляет отчёт с доказательствами и вручную оценивает объяснение по общей рубрике. Ручные отметки автора или наставника не повышают балл модели.
5. Проверяет другую причину. При наступлении срока возвращается к практике. На странице прогресса понимание, самостоятельное решение и отложенная проверка показаны отдельно.
6. Расширяет обучение через углублённые пакеты, неизвестные инциденты и собственный разрешённый стенд. Собственный отчёт стенда остаётся самостоятельной записью, не аттестацией приложения.

«Сегодняшняя задача», карта навыков и завершённый терминальный разбор используют `recommendNextTask`. Приоритеты: назначенный разбор ошибки, повторение, материал и понимание, практика без подсказок, новая причина, другая форма теории, стенд. Выбор направления учитывает порядок навыков и их предпосылки.

Редакторы лабораторий, курсов, графов и трасс доступны в отдельной авторской мастерской. Существующие ссылки на старые разделы, журнал, материалы и отчёты сохранены через `LegacyLearningPage`.

## Что означает прогресс

Правила собраны в `learningPolicy.ts`, версия 1: самостоятельная попытка — завершение, минимум 85 баллов, отсутствие подсказок и режим practice/exam. Для перехода нужны разные семейства причин, компетенции и формы проверки; косметическая смена адресов не создаёт новую причину. Для отложенной проверки используется интервал семь суток и окно суток для двух разных причин. Эти параметры — правила продукта, не подтверждённая научная шкала квалификации.

Старые записи без метаданных причины не получают вымышленные подтверждения. Будущие даты не учитываются в текущих учебных показателях. Результаты вне обновлённого направления L1 остаются в журнале и полной карте навыков.

## Код и данные

- `features/learning`: маршрут, экран занятия и контроллер одной сессии. Контроллер фиксирует ID занятия и ответ до сохранения, отвергает запоздалое обновление другого экрана.
- `features/workshop/recommendations.ts`: единая рекомендация. `learningFlow.ts` сохраняет прежний экспорт `todayTask` для совместимости.
- `features/workshop/professional/`: определения, схема, действия, оценка, адаптер старых результатов, репозиторий и экспорт разделены. Новые действия получают структурированные `outcome` и `violations`; новая оценка не зависит от текста сообщения. Завершённые исторические оценки не пересчитываются.
- Общая ручная рубрика доступна для терминальных и профессиональных отчётов. При изменении текста или доказательств прежний разбор считается относящимся к прежней редакции.
- При явном сохранении изменённого отчёта сохраняются три предыдущие редакции текста, выбранных ссылок и ручного разбора. История включается в локальный backup вместе с записью; Markdown указывает число редакций, полная история читается в интерфейсе или JSON-копии.
- Все новые поля в существующих схемах необязательны. Новая версия читает прежние записи; совместимость новой копии со старой версией приложения не гарантируется. Номер IndexedDB не менялся, новые таблицы не создавались. Лимиты и транзакционная проверка бюджета хранилища сохранены.
- TypeScript разделяет браузер и инструменты: `tsconfig.json` не добавляет Node globals в приложение, `tsconfig.tools.json` проверяет конфигурации и существующие исходники тестов без их запуска.

## Терминал

Токенизация и разбор вынесены в `commandSyntax.ts`. Значения аргументов сохраняют регистр: это важно для Linux-путей, SSID и флагов native curl. DNS-имена сравниваются без учёта регистра. `curl.exe` явно поддержан для Windows PowerShell 5.1; `curl -I` моделирует HEAD, `-i` не подменяет его.

Справочник использует явные контракты: среда, клиент/сервер/модель, чтение/изменение, права и поддерживаемая форма. Движок расширенных лабораторий проверяет, что изменение объявлено в контракте. Это ограниченный симулятор, произвольный shell и системные команды не исполняются.

## Современные материалы

Паспорта основных уроков показывают версию, среду, дату и объём содержательной сверки; остальные материалы явно ожидают повторной проверки. Доступная ссылка или прежняя редакционная отметка не объявляются проверкой на реальной ОС.

Обновлены контекст DNS приложения и кэширование ошибок ([RFC 8484](https://www.rfc-editor.org/info/rfc8484/), [RFC 9520](https://www.rfc-editor.org/info/rfc9520/)), HTTP/3 и границы TCP-проверки ([RFC 9114](https://www.rfc-editor.org/rfc/rfc9114.html)), рекомендации TLS ([RFC 9325](https://www.rfc-editor.org/info/rfc9325/)) и подпись SMB ([Microsoft Learn](https://learn.microsoft.com/en-us/windows-server/storage/file-server/smb-signing-overview)). Добавлены три задания на эти ситуации; QUIC и SMB signing не представлены как реализованные протокольные модели.

## Границы и дальнейшее развитие

Следующие этапы требуют отдельного подтверждения результатов: реальные Windows captures RU/EN на собственной VM, проверка удобства обучения с пользователями, клавиатурная и мобильная проверка интерфейса, восстановление полного набора автоматических проверок, отдельная миграция TypeScript 7 и инструментов. Приложение не обещает пригодность для любой учебной дисциплины: реализованный предмет — IT-диагностика.

Для версии 1.0 нужно подтвердить перенос навыка: незнакомая причина без подсказок, объяснение с наблюдениями и практическая проверка на настоящем стенде. Большой каталог сам по себе такого результата не доказывает.

# Участие

Используйте Node из `.nvmrc`, `npm ci` и `npm run dev`. Изменения делайте небольшими и независимыми. Пример коммита: `feat: add localized network output parser`.

Парсер и правило должны иметь синтетические fixtures, позитивные/негативные тесты и evidence. Текст UI — русский; code names — английские. Не добавляйте скрытую передачу или сохранение данных, backend «на будущее», unsafe автоматическое исправление или `any`/`@ts-ignore` для обхода типизации.

Перед PR: `npm run format`, `npm run check`, `npm run test:coverage`, `npm run test:e2e:all` в среде с тремя установленными движками. Быстрая локальная проверка — `npm run test:e2e` (Chromium). Не выдавайте отказ запуска движка за пройденный тест; укажите ограничения среды. В описании: проблема, итоговое поведение, проверки и ограничения. Не включайте реальные корпоративные данные, секреты и raw logs в отчёты ошибок.

Учебные вопросы требуют уникальных ID, объяснения и первичного источника. Новый сценарий должен проходить строгую схему и тест полного прохождения. Изменение progress/case schema требует миграции; неизвестные версии не принимать молча. Service Worker кеширует только allowlist файлов сборки: не добавляйте runtime-кэш пользовательских данных.

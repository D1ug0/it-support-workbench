## Совместимость и данные

БД остаётся v4; не требуется удалять старые stores или пользовательские записи. Общий backup остаётся v2, прежние v1/v2 читаются. Новые поля имеют совместимые значения по умолчанию. Завершённые инциденты прежней рубрики сохраняются как исторические; новый критерий им задним числом не приписывается. Новую копию используйте с текущей версией: старый строгий читатель 0.6.0 не знает добавленные поля.

Свободный текст сохраняется только по явной команде с прежним согласием. Сбор Windows raw не отправляет данные и не добавляет их в Git автоматически. Не менялись аккаунты, инфраструктура публикации или рабочие данные. Docker Desktop запущен по разрешению пользователя, временные контейнеры/сеть/образы проверки очищены.

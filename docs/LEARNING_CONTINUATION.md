# Продолжение обучения и адаптивность — 11.10.2026

Текущий этап рабочей версии 0.6.2. Формат прогресса, БД v4, backup v2, правила оценки и согласие на сохранение не меняются.

Дополнение следующего этапа: [короткая тренировка DNS-ошибок](ERROR_PRACTICE.md) имеет приоритет в сегодняшней задаче, сохраняет первые ответы и назначает проверку через сутки. Для этого добавлены совместимые поля прогресса; описание ниже относится к предыдущему изменению истории и адаптивности.

## Что видно пользователю

«Продолжить обучение» есть в учебном центре и практикуме. Пока сохранённый прогресс читается, блок показывает статус загрузки и не предлагает задачу, рассчитанную по пустому состоянию. После загрузки остаются прежние рекомендации, возврат к материалу курса и продолжение последнего сохранённого активного профессионального инцидента.

Если чтение инцидентов недоступно, появляется пояснение. Отсутствие доступа не выдаётся за пустую коллекцию и не блокирует остальное обучение. Повреждённая отдельная запись не выбирается для продолжения.

Раскройте «Единая история обучения»: показаны последние 30 событий по времени, сначала новые. У каждой записи есть название вопроса/задания, раздел, навык при наличии, результат, оценка и дата. Ошибки остаются рядом с попыткой. Сортировка не изменяет сохранённый порядок; для истории учитывается её исходный лимит 500 событий.

Результаты: «Выполнено», «Нужна повторная попытка», «Самостоятельный отчёт», «Достигнут предел шагов», «Попытка прервана». Нулевая оценка показывается как 0 / 100; отсутствие оценки не превращается в ноль. Отчёт настоящего стенда остаётся самостоятельным заявлением без автоматической аттестации. Даты отображаются на русском языке в часовом поясе устройства.

## Названия и прежние данные

Названия берутся из существующих каталогов вопросов, курсов, пакетов, практики, тренажёра, терминала, расследований, профессиональных инцидентов и стенда. Доступные авторские лаборатории/курсы/графы используют своё название. Для авторского линейного инцидента здесь показывается общий тип, поскольку этот блок не загружает его отдельный каталог.

Удалённые/недоступные материалы получают понятное запасное название. Старое событие пакета помечается заданием прежней версии: современная формулировка не приписывается ему задним числом. Исходные ID и записи остаются в прогрессе и резервной копии; чтение истории не создаёт новых попыток и не сохраняет текст вопроса дополнительно.

## Причина падения CI

[CI коммита 9222949](https://github.com/D1ug0/it-support-workbench/actions/runs/38089055432) прошёл format/lint/unit coverage/companion/build, но четыре E2E Firefox/WebKit/Linux упали на `/playbooks`: scrollWidth 346 при viewport 320. На скриншоте за край выходило слово «Последовательность». Flex-блок не сжимался, у заголовка был обычный перенос текста; результат зависел от системного шрифта.

У `.page-heading > div` теперь `min-width: 0`, у `.page-heading h1` — `overflow-wrap: anywhere`. Горизонтальная прокрутка не маскируется обрезанием страницы. Новая регрессия на 320 px с Arial/Verdana проверяет ширину документа, границы заголовка и отсутствие обрезанного текста в обеих темах. На прежней сборке WebKit/macOS она упала с шириной 341 px.

Проверки: `learningHistory.test.ts`, `ContinueLearning.test.ts`, новые сценарии `visual-ui.spec.ts` и `audit-fixes.spec.ts`; результаты и ограничения — [VALIDATION.md](VALIDATION.md).

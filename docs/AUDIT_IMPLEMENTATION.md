## Данные и перенос

Общая Dexie БД повышена до v4 добавлением `scenarios`, `drafts`, `metadata`, `professionalAttempts`. Ни один прежний store не удалён. Прогресс практикума v1 принимает новые необязательные поля `events`, `theoryChecks` и metadata попытки. Пустые массивы при чтении старых данных не означают новое подтверждение навыка. Базовый прогресс v1/v2/v3 сохраняет прежние миграции; новые события могут содержать UUID попытки.

Обычный backup экспортируется компактным JSON. Все пути накопления учебных материалов проверяют общий бюджет до commit. Восстановление проверяет токен текущих записей и выполняет замену в одной IndexedDB-транзакции. Копии v1 не удаляют коллекции, которых в старом формате не было. Копии v2 заменяют перечисленные учебные коллекции целиком; исходные старые БД остаются доступными для recovery export. Предпросмотр описывает замену.

Заметки сохраняются только по явному действию с согласием. Ссылки на синтетические команды добавляются выбором пользователя. Обезличенные реальные результаты можно прочитать в сравнении стенда, они не включаются в backup/черновик автоматически. Рабочие кейсы, архивы, terminal checkpoints, clipboard и офлайн-кэш имеют отдельное управление.

Общий пакет содержит до 20 лабораторий, 20 курсов, 20 графов, 20 линейных инцидентов, 50 отчётов портфолио, 50 отчётов стенда, 50 черновиков и 50 профессиональных попыток. Прогресс практикума — 500 попыток, 500 объединённых событий, 300 теоретических проверок, 100 отметок уроков; отдельный импорт до 12 MiB. Companion сознательно оставляет API-предел 256 KiB и предлагает JSON для более крупного прогресса. Панель преподавателя — до 20 учеников, 12 MiB на файл и 16 MiB вместе.

## Проверки и внешние условия

Актуальные результаты находятся в [VALIDATION.md](VALIDATION.md). Чистые регрессии: `auditRegressions.test.ts`, store терминала; настоящие IndexedDB-процессы: `e2e/audit.spec.ts` и прежний `e2e/evolution.spec.ts`; HTTP/SQLite — `server/companion.test.mjs`. Полная браузерная матрица и coverage остаются в GitHub CI. Успешный прежний CI не подтверждает эту рабочую версию.

Для дальнейшего подтверждения B04/B06 нужны разрешённые Windows/Linux captures, версия ОС/локаль, ручной разбор на реальном стенде. Учебную полезность длинных инцидентов нужно оценить с учеником; автоматическая проверка достижения целей этого не заменяет.

# Продвинутый курс IT Support Workbench

Откройте **Учебный центр → Продвинутый курс**. Восемь модулей содержат объяснения, команды для ручной проверки, последовательность диагностики, первичные источники и синтетическую лабораторную. Четыре решения на модуль — 32 дополнительных задания. Базовые 30 вопросов и шесть инцидентов остаются доступны отдельно.

## Маршрут

| Модуль                       | Навык                                                       | Практическая ситуация                           |
| ---------------------------- | ----------------------------------------------------------- | ----------------------------------------------- |
| HTTPS и доверие сертификатам | Разделять TCP, TLS и HTTP; сравнивать имя, срок и доверие   | Разные клиенты видят разные сертификаты         |
| DNS: SRV, кэш и split DNS    | Учитывать тип записи, резолвер и политику пространства имён | Прямой запрос работает, системный — нет         |
| Active Directory и Kerberos  | Связывать DNS, пользователя, билеты и источник времени      | Кэшированный вход успешен, служба сообщает SKEW |
| SMB и права доступа          | Проверять контекст SMB и совместное действие share/NTFS     | Чтение доступно, создание файла запрещено       |
| Групповые политики           | Разделять user/computer scope и читать denied reasons       | Политика отфильтрована по группе                |
| IPv6 и двойной стек          | Различать link-local, глобальную цель и маршрут             | IPv4 работает, пути к глобальному IPv6 нет      |
| VPN: пересечение сетей и MTU | Выбирать маршрут по префиксу и интерпретировать DF-пробы    | Локальная подсеть перехватывает удалённую цель  |
| Wi-Fi                        | Сопоставлять BSSID, место, IP и одинаковые пробы            | Одна точка, разные условия радиосвязи           |

Начните с базового маршрута. DNS полезно пройти до Active Directory и VPN; AD — до SMB и GPO. Предпосылки видны на карточках и не блокируют доступ. Указанное время — ориентир для занятия, а не измеренный срок освоения.

## Как проходить модуль

1. Прочитайте цели и три объяснения. Перескажите механизм своими словами.
2. Посмотрите, что проверяет каждая команда и чего она не подтверждает. Приложение ничего не выполняет; реальные проверки допустимы только в разрешённой среде.
3. Прочитайте все свидетельства лабораторной. Разделите наблюдение, гипотезу и следующий эксперимент.
4. Ответьте на четыре вопроса. Первый выбор фиксируется для этой попытки. Подсказка помогает рассуждать и отмечается в итоговом разборе; объяснение раскрывается после ответа.
5. Скачайте Markdown-разбор. Он содержит вымышленный исходный контекст, выбранные решения, верные варианты, объяснения, подсказки, следующие проверки и ссылки.
6. Повторите ошибки после объяснений. Затем используйте расписание повторений для возвращения к теме.

Поиск доступен внутри курса, в справочнике и через Ctrl/⌘+K. Ссылка `/#/learning?course=tls` открывает конкретный модуль; неизвестный ID не запускает произвольный материал. Изменение выбранного модуля сбрасывает текущую незавершённую лабораторную; уже отвеченные задания остаются в учебном прогрессе.

## Повторение и прогресс

- Верный ответ назначает повторение через 1 день. Последующие верные ответы по наступившему сроку увеличивают интервал до 3, 7, 14 и 30 дней; дальше остаётся 30 дней.
- Ошибка сбрасывает серию и назначает повторение через 10 минут. Базовые последние ошибки можно разобрать сразу; лабораторную можно пройти заново. После исправления начинается интервал 1 день.
- Ответ раньше наступления срока не увеличивает уже положительную серию. Простое многократное нажатие не позволяет отложить повторение на месяц.
- Подборка включает отвеченные базовые и продвинутые задания с наступившим сроком; последние ошибки получают приоритет. Новые вопросы в неё не добавляются автоматически.
- Время вычисляется по часам устройства, даты хранятся в UTC и показываются в местном времени. Подборка обновляется раз в минуту на открытой странице или по кнопке. Фоновых уведомлений нет.
- Это простое детерминированное расписание, не научно валидированная модель памяти и не оценка профессиональной готовности.

Прогресс `schemaVersion: 2` хранит счётчики, оценки лабораторных и даты повторений. Старый JSON v1 и существующая запись IndexedDB читаются с сохранением счётчиков. Даты для старых ответов не придумываются: они предлагаются к повторению, после которого появляется расписание. Экспорт создаёт v2; предыдущая версия приложения не умеет читать новый формат.

Постоянная запись включается прежним переключателем сохранения прогресса. Без него данные остаются в памяти вкладки. Незавершённые решения и подсказки лабораторной не сохраняются на диск; экспорт разбора доступен после завершения. В IndexedDB попадают ID ответов, счётчики, даты и итоговые оценки, а не диагностический текст или свободные заметки. История хранит число завершённых попыток и лучшую оценку, без подробного журнала каждой попытки.

При включённом сохранении дождитесь сообщения «Прогресс сохранён на устройстве» перед перезагрузкой. Счётчик на экране обновляется сразу, а запись в IndexedDB завершается асинхронно. Статус показывает всю очередь записи; при отказе хранилища интерфейс сообщает об ошибке и предлагает экспорт.

## Дальнейшая практика

Выполняйте по одному модулю за занятие, затем возвращайтесь к расписанию. Для лаборатории объясните: **что известно → чего не хватает → какая проверка различит гипотезы → кому передать результат**. Только после этого переносите подход в согласованную учебную среду Windows.

Чтение материалов и лабораторные работают офлайн после включения офлайн-доступа. Переходы к Microsoft Learn, curl и RFC Editor требуют сети. Дата сверки источников текущего каталога — 10.10.2026; поддерживаемые команды и условия применения нужно уточнять для целевой Windows.

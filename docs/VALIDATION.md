## Подтверждённые пользовательские сценарии

- Демопример → реальный Worker → карточки адаптеров → evidence → обезличенное скачивание → очистка.
- Стандартные RU/EN fixtures пяти команд, неполный/ошибочный ввод, корректные IPv4/IPv6 и маски, безопасные гипотезы без ложного подтверждения доступности сети.
- Локальный File API, отказ на бинарном/слишком большом файле, ручные кодировки. Позднее чтение файла не возвращает очищенный или заменённый ввод.
- Отсутствие внешних запросов и localStorage/sessionStorage в обычном сценарии анализа; reload сбрасывает ввод. HTML/script из fixture выводятся текстом.
- Обезличенный отчёт исключает частные адреса и идентификаторы. Raw требует отдельного подтверждения. Escape закрывает диалог.
- CIDR `/31`, `/32` и ошибка IPv4; поиск/сброс справочника; учебный сценарий с ошибочным действием, объяснением и итоговой оценкой. Unit-тесты проходят все шесть сценариев.
- Явное сохранение кейсов, сохранность после reload, сравнение двух отчётов, удаление с подтверждением. JSON сначала показывает предпросмотр; неизвестная версия отклоняется и не оставляет старый предпросмотр.
- Mobile width 360/375 px; dark/light themes; skip link сохраняет hash route; Axe не обнаружил serious/critical нарушений на проверенных маршрутах, в результатах анализа и отчёте.
- Production-файлы и Worker работают из `/preview/site/` на статическом сервере без SPA rewrites.
- Синтетический `ping` с 30 000 ответами обрабатывается в Worker; UI показывает 80 строк результата, навигация открывает следующие строки, очистка удаляет результат.
- Явная сессия из четырёх проверок → корреляция DNS → семантический до/после → общий обезличенный отчёт со ссылками на номера сравниваемых проверок → reload удаляет сессию.
- IPv6 canonicalization, дубликаты интерфейсов, перестановки адресов и шлюзов, все пять моделей diff; не подменяется смысл строк маршрута.
- Учебный прогресс по умолчанию исчезает после reload; opt-in сохраняет его. Ошибочный ответ можно повторить; неизвестная версия импорта отвергается.
- Чек-лист: отметка → Markdown download → reset. Глобальный поиск открывает знания с клавиатуры.
- Longest-prefix /32 имеет приоритет перед более дешёвым default route; переход к evidence выделяет нужную исходную строку сразу после монтирования.
- Импортированные даты с разными ISO-миллисекундами сортируются правильно; кейс переименовывается и находится фильтром. Unit round-trip всех частей большого архива соблюдает 2 MiB.
- Офлайн: нет автоматической регистрации → явное включение → только статические ресурсы в кэше, без приватного marker → reload без сети → анализ настоящим Worker → ленивый учебный раздел → отключение. Проверено с корня и `/preview/site/` в двух движках.
- Устаревшие Worker callbacks, отказ создания Worker, некорректный RTT/счётчики/метрики дают безопасное поведение.
- Помощник требует два ответа, адаптирует Wi-Fi/USB/неизвестный контекст, экспортирует отметки. Тип консоли указан в интерфейсе и Markdown. План сохраняется между разделами, удаляется при reload и очистке настроек; переход не заменяет ввод анализатора.
- Краткое объяснение пяти моделей связано с evidence; словарь находит термин через глобальный поиск. Учебный маршрут приоритизирует последнюю ошибку и запускает нужный сценарий. Практика подсетей проверяет формат, объясняет неверный ответ и учитывает решённую задачу один раз.
- Офлайн-проверки включают ленивый помощник и вычислительное упражнение с корня и подпапки. Видимость нижнего пункта меню проверяется при 1280×900; новые панели проверяются при 360 px и в обеих темах.

## Практические границы проверки

Данные вымышленные. Реальные системы/устройства не проверялись. Axe не является полной сертификацией WCAG; screen reader и установку отдельного окна на целевых устройствах не проверяли. Обновление Service Worker не использует принудительную активацию/перезагрузку; многовкладочный цикл обновления на реальном хосте требует отдельной проверки. Аудит пакетов не доказывает отсутствия всех уязвимостей.

Firefox завершается до создания страницы с `Could not find profile folder`, включая попытку с отдельным временным профилем. В Mozilla описан [сходный отказ профиля при CLI-запуске в macOS 27](https://bugzilla.mozilla.org/show_bug.cgi?id=2062988); вероятная причина среды, не подтверждённый диагноз этого устройства. Права macOS и пользовательские профили не менялись. Firefox включён в CI на Linux, но удалённый результат ещё не получен. В WebKit/macOS keyboard test использует Option+Tab согласно поведению платформы; сессии навигируют через Vue Router, сохраняя память.

GitHub-репозиторий, commit/push, удалённый CI-run и Pages URL не создавались. Workflows подготовлены, но их успешный запуск на GitHub нужно подтвердить после публикации репозитория. Временные серверы этой проверки остановлены. Запуск приложения: `npm run dev`.

Все 12 разделов реализованы. Границы и следующие расширения: [IMPROVEMENTS.md](IMPROVEMENTS.md), [ROADMAP.md](ROADMAP.md).

Шаг допуска Pages проверен с имитацией GitHub API: успешный CI допускает продолжение, отсутствие успешного CI или ошибка API останавливают workflow. Это проверка локальной логики конфигурации, не запуск GitHub Actions.

# Состояние реализации и развитие

Локальная версия `0.3.0`. Этапы M0–M8 соответствуют ТЗ, а не номерам опубликованных релизов.

| Этап | Состояние                  | Реальный результат                                                                                       |
| ---- | -------------------------- | -------------------------------------------------------------------------------------------------------- |
| M0   | Готов локально             | Vue/strict TypeScript/Vite, hash routes, темы, адаптивный layout, quality tools                          |
| M1   | Готов                      | RU/EN ipconfig, несколько адаптеров, продолжения, partial parse, fixtures                                |
| M2   | Готов                      | NET-001…008, evidence, ограничения и следующий шаг                                                       |
| M3   | Готов                      | Файлы, кодировки, очистка, обезличенный экспорт и raw consent                                            |
| M4   | Репозиторий и CI готовы    | Исходники опубликованы пользователем; исправление main прошло Linux CI; Pages запускается отдельно       |
| M5   | Готов в описанных форматах | Пять RU/EN парсеров, рабочие сессии, контекст/время, семантическое сравнение и общий отчёт               |
| M6   | Готов                      | CIDR /0…/32, longest-prefix маршрут, 14 портов, команды, 18 карточек знаний                              |
| M7   | Готов и расширен           | 6 JSON-инцидентов; 30 базовых вопросов, 8 продвинутых лабораторных / 32 решения, интервальное повторение |
| M8   | Готов                      | Opt-in кейсы, JSON preview/import, экспорт частями, фильтры/rename, опциональный офлайн                  |

Дополнительно: помощник по пяти симптомам, понятное объяснение пяти моделей, 18 терминов, учебный маршрут с рекомендациями, 8 задач по подсетям, 6 чек-листов с экспортом, глобальный поиск с клавиатуры, настройки данных. Всего 12 рабочих разделов; продвинутый курс встроен в учебный центр. Репозиторий опубликован пользователем; Pages остаётся отдельным ручным шагом. Новые изменения курса пока готовятся локально.

## Следующие содержательные улучшения

1. **Редактор учебных инцидентов.** Валидируемый JSON-конструктор, предпросмотр дерева шагов и импорт пользовательских сценариев. Требует проверки графа на тупики, недоступные шаги и повторы баллов.
2. **Открытые практические задания.** Ответы расчётом или структурированным планом с проверяемыми критериями. Сейчас 32 решения продвинутых лабораторных выбираются из вариантов; интервальное повторение уже реализовано в прогрессе v2.
3. **DNS MX/TXT/SRV и PowerShell.** Отдельные типы моделей и RU/EN fixtures, корректное разделение ответов/ошибок. Не расширять A/AAAA-парсер угадывающими regex.
4. **Обезличенный структурированный архив сессий.** Модели без источника с явным согласием, стабильными маскированными ID и миграциями. Сейчас сессии в памяти, постоянные кейсы — текстовые отчёты.
5. **Проверка реальных Windows-форматов.** С разрешения владельца данных подготовить обезличенные fixtures разных версий и локалей. Проверить screen reader, установку приложения и lifecycle обновлений на целевых устройствах.

EVTX, AI, backend, remote agent, сканирование LAN и автоматическое изменение конфигурации не входят в реализацию. Публичное размещение — отдельное решение владельца репозитория.

Разбор выполненных улучшений: [IMPROVEMENTS.md](IMPROVEMENTS.md). Инструкции для практики: [PRACTICE.md](PRACTICE.md).

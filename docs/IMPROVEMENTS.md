## Исправленные дефекты

- Архив крупных кейсов мог превышать лимит собственного импорта. Теперь экспорт делится на части до 2 MiB; unit-тест импортирует каждую часть обратно.
- Лексикографическая сортировка ISO-дат ошибалась при разных миллисекундах. Теперь сортируется фактическое время.
- Повторный import-click мог менять предпросмотр во время записи. Операция использует snapshot и блокировку UI; транзакция атомарна.
- Поздние callbacks отменённого Worker могли подменять результат. Проверяется экземпляр; отказ конструктора показывает явную ошибку.
- Несогласованный RTT, небезопасные счётчики и дробные метрики больше не выглядят корректными: добавлены проверки и предупреждения.
- Source-line, выбранная до монтирования viewer, теперь сразу открывает нужное окно.
- Diff сохраняет связь сети/шлюза/интерфейса/метрики в строке. Перестановка шлюзов не теряется при сравнении независимых списков.
- Эквивалентные IPv6 и перестановки адресов не дают ложный diff; одинаковые имена интерфейсов явно неоднозначны.
- Маскирование сессионного отчёта согласовано между проверками; названия, контекст, метки и raw исключены.
- В отчёте указаны номера проверок «до/после». Сравнение tracert учитывает смену цели и RTT каждого хопа, включая `<1 ms` и тайм-ауты.
- Service Worker нормализует hash URL и учитывает `Vary: Origin` только для статической allowlist. Reload и Worker без сети проверяются с корня и подпапки.
- Cache version учитывает код генератора, чтобы изменение политики кэша получало собственную версию.

## Сохранённые границы

Приложение не получает конфигурацию компьютера само и не выполняет команды. Наблюдения основаны на предоставленном тексте и не доказывают исправность сервиса. Поддерживаются пять стандартных форматов Windows CMD на RU/EN; DNS MX/TXT/SRV, PowerShell objects и другие локали требуют дальнейшей реализации.

Источники сессий намеренно не сохраняются постоянно. Перезагрузка очищает их; нужный итог следует экспортировать заранее. Кейсы и прогресс требуют явного действия и хранятся отдельно. Офлайн-кэш не заменяет резервную копию кейсов.

Каталог конечный: 30 базовых вопросов, 32 решения восьми продвинутых лабораторных, 8 задач по подсетям и 6 инцидентов. Он развивает логику диагностики, но не заменяет практику Windows, сети и устройств. Баллы — результат учебных заданий. Базовый маршрут учитывает последние ответы; отдельное расписание назначает интервальное повторение. Практика подсетей сбрасывается при уходе из инструментов.

Firefox e2e запускается в CI Linux; bundled Firefox в текущей macOS не запускается. Chromium/WebKit проверяются отдельно. Исправление main уже прошло удалённый CI; новые изменения продвинутого курса требуют собственного CI после push пользователя.

## Продвинутое обучение — 10.10.2026

- Добавлены восемь уроков по TLS, DNS/SRV, AD/Kerberos, SMB, GPO, IPv6, VPN/MTU и Wi-Fi. Каждый связывает объяснение, команды, первичные источники и вымышленные свидетельства.
- Лабораторные фиксируют первый выбор, отмечают подсказки, показывают ошибки и скачивают полный Markdown-разбор. Итоговые попытки и лучшая оценка используют прежнее opt-in хранилище.
- Прогресс v2 содержит даты повторений; v1 читается без потери счётчиков. Старым ответам не придумывается история.
- Расписание 1/3/7/14/30 дней не увеличивает серию за ответы раньше срока. Ошибка назначает короткое повторение. Подборка охватывает оба каталога, без автоматического добавления неотвеченных заданий.
- Продвинутые темы находятся в справочнике, поиске и прямых ссылках. Тип консоли для команды можно передать явно; Resolve-DnsName больше не маркируется как CMD.
- Исправлен импорт реактивного предпросмотра, вызывавший ошибку `structuredClone` Vue proxy. Статус записи прогресса теперь показывает завершение всей очереди IndexedDB; обновление счётчика в памяти больше не выдаётся за подтверждение сохранения.

Границы: нет открытых письменных ответов, детальной истории каждой попытки или фоновых уведомлений. Расписание зависит от часов устройства. Непройденная лабораторная остаётся в памяти. Обновление TypeScript и настройки GitHub к этой работе не относятся.

Следующие содержательные расширения: [ROADMAP.md](ROADMAP.md).

## Самостоятельное обучение и продолжение диагностики

Добавлены 24 открытых учебных задания, журнал 500 последних попыток и недельные цели с миграцией v3. Новые DNS MX/TXT/SRV и PowerShell JSON связаны с evidence, понятными объяснениями, сравнением и безопасным отчётом. Редактор собственных линейных инцидентов использует общий engine и строгую схему; его тексты сохраняются только после подтверждения учебных данных. Сессии можно явно архивировать в обезличенной структурированной форме и восстановить для сравнения после reload. Все новые возможности доступны из существующих разделов и поиска.

Практические инструкции: [LEARNING_WORKSHOP.md](LEARNING_WORKSHOP.md), [SESSION_ARCHIVE.md](SESSION_ARCHIVE.md). Границы: авторский текст сценария не обезличивается автоматически; архив не содержит исходников/реальных адресов; фактические Windows-форматы проверены пока только синтетическими fixtures.

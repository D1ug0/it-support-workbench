# Пять исправлений надёжности — 16.10.2026

Исходный коммит: `5048582`. Изменения подготовлены в пяти отдельных локальных коммитах без отправки в remote.

1. Анализатор: синхронная ошибка `Worker.postMessage` снимает статус обработки, освобождает Worker и таймер и позволяет повторить анализ. Удаление Pinia store также завершает работу; поздние ответы игнорируются.
2. Авторские материалы: успешное удаление сбрасывает CAS-токен в store и открытых редакторах. Повторное сохранение лаборатории, курса или графа не вызывает ложный конфликт. Неудачное удаление сохраняет прежний токен.
3. Очередь прогресса: перед началом записи повторно проверяется opt-in. Отзыв согласия отменяет ожидающие снимки, даже при быстром повторном включении; результаты остаются в RAM. Уже начатая транзакция завершается перед сериализованным отключением.
4. Архитектурный контроль: распознаёт строковые обращения к браузерным API, деструктуризацию `globalThis` и прямое присваивание API переменной. Native Node-проверка включает ленивые импорты `.ts`. Whitelist не расширен.
5. Companion: слишком большой ответ отменяется как по `Content-Length`, так и во время потокового чтения. Ошибка отмены не скрывает причину превышения лимита 256 KiB; блокировка reader освобождается.

Новые регрессионные проверки воспроизвели исправляемые ошибки до изменения реализации. Схемы, миграции, версии БД, ID хранилищ, форматы экспорта и зависимости не изменены.

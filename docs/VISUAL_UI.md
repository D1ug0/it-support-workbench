# Интерфейс 0.6.2

Исправления по трём пользовательским скриншотам, 11.10.2026. Наложение в терминале возникало из-за общего класса `.network-map`: декоративная схема главной задавала flex-строку всему содержимому учебной карты. Теперь она использует отдельный `.terminal-network-map`. Карта показывает то же состояние модели, с отдельными карточками узлов, деталями, маршрутом и временем; смена лаборатории сбрасывает выбранный узел.

## Селекты

Все 42 селекта в 20 Vue-компонентах используют `src/shared/components/AppSelect.vue` и `AppSelectOption.vue` на [Reka UI 2.11.0](https://reka-ui.com/docs/components/select). Обёртка задаёт общую геометрию, цвета из темы, отметку выбора и меню. Список позиционируется через popper, ограничен размером экрана, прокручивается и остаётся в top layer внутри native dialog. Сохраняются `disabled`, названия полей, Arrow/Home/End, Enter/Escape, поиск пункта по начальным буквам и возврат фокуса.

```vue
<label>
  Режим
  <AppSelect v-model="mode" :disabled="busy" @change="restart">
    <AppSelectOption value="guided">Обучение</AppSelectOption>
    <AppSelectOption value="exam">Проверка</AppSelectOption>
  </AppSelect>
</label>
```

`change` передаёт выбранное значение, а не DOM Event; `update:modelValue` обновляет модель первым. Для чисел передавайте `:value="i"`, без `.number`. Пустая строка и null допустимы: внутреннее кодирование сохраняет их тип, хотя библиотека резервирует пустую строку. Не задавайте компоненту массив значений: это одиночный выбор. Стили находятся в `src/shared/styles/select.css`; они подключаются один раз и используют существующие токены светлой/тёмной темы. В приложении нет оставшихся нативных селектов; библиотека может создавать служебный скрытый select для форм.

## Остальные исправления

- Шапка помещается на 320 px, кнопки переносят длинные подписи, поля имеют единый размер, чекбоксы не теряют flex-размещение внутри практикума.
- Группы полей оформлены рамками/легендами; навигация практикума компактнее, на мобильном экране прокручивается горизонтально.
- Длинное название в закрытом селекте сокращается многоточием; полностью прочитать его можно в открытом меню.
- При смене темы фон селекта меняется сразу вместе с текстом. Анимация не создаёт временно неконтрастную комбинацию цветов.
- Выбор демопримера включает автоопределение формата. Очистка/новый ввод/файл убирают устаревшую отметку примера.
- Ответ базового обучения ставится в очередь записи до ожидания другого журнала. Статус сохранения относится к фактической записи текущего снимка.

## Проверка

`e2e/visual-ui.spec.ts` проверяет 13 главных страниц и дополнительные разделы практикума на 1440/1024/768/390/320 px в обеих темах: горизонтальное переполнение, геометрию карты, клавиатурное управление, сохранение значения/фокуса, длинные подписи, меню в диалоге, пустой пункт и числовой вариант. Axe проверяет страницу при закрытом меню, WCAG-контракт открытого меню и окно отчёта. Горизонтальная прокрутка навигации на мобильном устройстве допускается явно.

Прежние E2E используют `e2e/helpers/select.ts`: он открывает настоящий combobox и нажимает пункт portalled listbox. Скрытый служебный select не используется для обхода нового UI. Дополнительно сохраняются старые проверки мобильных экранов, альтернативного шрифта, приватности, сохранения, offline и терминального ввода. Regression базового журнала проверяет задержку независимого журнала отдельно от собственной записи.

После сборки:

```sh
npm run test:ui
npm exec --no -- playwright test --project=chromium
```

Актуальные результаты и ограничения движков указаны в [VALIDATION.md](VALIDATION.md).
